# Basic Data Validation – Employee Template
## Task Overview
Created an employee data-entry template using Google Sheets with dropdown lists and data validation rules to improve data accuracy and prevent incorrect entries.

## Dataset
Synthetic Employee Data (sample employee records).

## Sheets Included
1. **Employee Data** – Contains employee details such as Employee ID, Name, Department, Employment Type, Joining Date, Age, Email, and Salary.
2. **Dropdown Lists** – Contains predefined Department and Employment Type options.

## Data Validation Applied
- **Department:** Dropdown options – IT, HR, Sales, Finance.
- **Employment Type:** Dropdown options – Full-time, Part-time, Contract, Intern.
- **Age:** Restricted between 18 and 60.
- **Salary:** Must be greater than zero.
- **Joining Date:** Only valid dates are accepted.

## Testing
Tested the validation rules using incorrect entries to ensure invalid data was rejected.

## Tools Used
- Google Sheets

## Outcome
Created a validated employee data-entry template that helps maintain accurate and consistent employee information.
